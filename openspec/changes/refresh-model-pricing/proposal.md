## Why

模型价格表当前只在应用启动时加载，长期驻留的菜单栏应用跨天后仍会继续使用旧价格；同一天远程价格变化时，用户也只能通过退出应用和删除缓存来刷新。需要让价格表在运行期间保持按日新鲜，并提供明确的手动刷新入口。

## What Changes

- 应用运行期间定期检查模型价格日期，跨天后自动拉取并应用最新价格
- Popup 每次展示时补充检查价格新鲜度，覆盖休眠、唤醒和定时任务延迟场景
- 设置窗口的数据页增加模型价格手动刷新入口，强制绕过当天缓存拉取远程价格
- 刷新成功后原子更新内存价格表并通知 Popup 重新计费；失败时保留现有价格并允许后续重试
- 增加刷新状态反馈和中英文文案

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `pricing`: 从仅启动时加载扩展为运行时按日检查、强制远程刷新和失败保留旧价格
- `tauri-bridge`: 增加价格刷新 command 和价格更新事件

## Impact

- Rust：`pricing` 加载与缓存逻辑、`AppState` 共享状态、后台刷新任务和 Tauri command 注册
- React：Settings 数据页刷新控件、Popup 价格更新监听、共享类型和国际化文案
- 测试：定价刷新决策、共享状态更新、设置页手动刷新和 Popup 事件响应
- 不新增外部依赖，不修改 Token 数据库结构或 Agent 数据读取链路
